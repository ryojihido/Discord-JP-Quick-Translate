# 導入・更新手順

Discord JP Quick Translate は、パソコンの Chrome で開いた Discord の文章を、クリックしたときだけ翻訳する拡張機能です。Discord のデスクトップアプリやスマートフォンでは使えません。

## 使う前に

- **Discord とは関係のない非公式拡張です。** Discord による承認・提携・後援は受けていません。
- **Chrome ウェブストアには掲載していません。デベロッパーモードを有効にして、手動で読み込む必要があります。** 自動更新もありません。
- Discord のページに表示されたメッセージを読み取り、翻訳ボタンを追加します。翻訳をクリックすると、対象の文章を選択した DeepL または Google の翻訳 API へ送ります。開発者の中継サーバーは使いません。
- 自分で取得した翻訳サービスの API キーが必要です。サービスの契約・利用量に応じて費用がかかる場合があります。キーは他人に渡さず、共有する画像にも写さないでください。
- 機密情報など、外部の翻訳サービスへ送れない文章には使わないでください。送信範囲・保存内容は [README](../README.md#プライバシーと保存) に記載しています。

必要なのは **Chrome 114 以降と、翻訳サービスの API キー**です。Chrome は最新の安定版を推奨します。下記のビルド済み ZIP を使えば、Node.js のインストールやコマンド入力は不要です。

## 1. ZIP をダウンロードして展開する

[ビルド済み ZIP（v1.0.2）をダウンロード](https://github.com/ryojihido/Discord-JP-Quick-Translate/releases/download/v1.0.2/Discord-JP-Quick-Translate-v1.0.2.zip)

[配布ページ](https://github.com/ryojihido/Discord-JP-Quick-Translate/releases/tag/v1.0.2) の「Assets」から選ぶ場合は、**`Discord-JP-Quick-Translate-v1.0.2.zip`** を選びます。GitHub が自動で表示する「Source code (zip)」は開発者向けのソースコードなので、この手順では使いません。

1. ダウンロードした ZIP を展開します。Windows では ZIP を右クリックして「すべて展開」を選びます。
2. 展開したフォルダーを、「ドキュメント」の中など、使い続ける場所に置きます。フォルダー名は `Discord-JP-Quick-Translate` などにして構いません。
3. フォルダーを開き、`manifest.json`（拡張子が非表示なら `manifest`）があることを確認します。同じ場所に `assets` や `icons` フォルダーがあります。

**ZIP を開いて中身を見るだけではなく、必ず展開してください。読み込み後もこのフォルダーを使うため、移動・削除しないでください。**

## 2. Chrome に手動で読み込む

1. Chrome のアドレスバーに `chrome://extensions/` と入力して開きます。
2. 右上の「デベロッパーモード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」を押します。
4. 先ほどの **`manifest.json` が入っているフォルダー**を選びます。ZIP ファイルや `manifest.json` 自体を選ぶのではありません。
5. 一覧に「Discord JP Quick Translate」が表示され、オンになっていることを確認します。

この配布 ZIP では `manifest.json` が展開したフォルダーの直下にあります。`dist` というフォルダーを別に探す必要はありません。

会社や学校の管理する Chrome で操作が制限されている場合は、管理者のルールに従ってください。

## 3. 翻訳サービスを設定する

1. Chrome 右上の拡張機能ボタン（パズルの形）から「Discord JP Quick Translate」を開き、「設定を開く」を押します。
2. 利用するサービスの API キーを入力します。どちらか一方だけで使えます。
   - **DeepL API Free**：[DeepL API の案内](https://www.deepl.com/ja/pro-api)から API Free のキーを取得し、「DeepL API キー」欄に入力します。この拡張は DeepL API Pro の接続先には対応していません。
   - **Google Cloud Translation**：[Google Cloud Console](https://console.cloud.google.com/)で Cloud Translation API を有効化し、作成したキーを「Google Translate API キー」欄に入力します。キーの API 制限を Cloud Translation API に設定し、利用枠・料金も確認してください。
3. 「使用する翻訳サービス」で、キーを入力したサービスを選びます。エラーになっても別のサービスへ自動では切り替わりません。
4. 「翻訳先言語」を確認し、「設定を保存」を押します。

入力欄の「テスト」は接続確認に使えます。入力中のキーで `Hello` を実際に翻訳するため、保存前でも通信し、API 使用量に含まれます。

## 4. Discord で使う

1. Chrome で [Discord](https://discord.com/app) を開きます。すでに開いている場合はタブを再読み込みします。
2. 翻訳したいメッセージにマウスを重ね、「翻訳」を押します。
3. 翻訳文が本文の下に表示されます。同じボタンで表示・非表示を切り替えられます。

止めたいときは拡張のポップアップで OFF にできます。送信済みの翻訳要求を取り消す機能ではありません。

## 新しいバージョンへ更新する

この配布方法では自動更新されません。[リリース一覧](https://github.com/ryojihido/Discord-JP-Quick-Translate/releases)で新しいバージョンを確認してください。

1. 新しいビルド済み ZIP をダウンロードし、一時的な別フォルダーに展開します。
2. **中身のファイルとフォルダーを、現在 Chrome に読み込ませているフォルダーへコピーして上書きします。** 展開したフォルダー自体をその中へ入れないでください。`manifest.json` の場所が変わらないようにします。
3. `chrome://extensions/` を開き、既存の「Discord JP Quick Translate」の再読み込みボタン（丸い矢印）を押します。
4. バージョン表示が更新されたことを確認し、Discord のタブも再読み込みします。

同じ場所・同じ登録を更新する場合、保存済みの API キーは通常そのまま使えます。**更新のために拡張を「削除」したり、別のフォルダーから新規登録したりしないでください。** 別の登録になると設定が引き継がれないことがあります。

自分でソースコードからビルドして導入済みの場合は、これまでと同じ `dist` を更新してください。ビルド済み ZIP を使って更新する場合も、その中身を既存の `dist` へコピーします。

## うまくいかないとき

| 症状 | 確認すること |
| --- | --- |
| 読み込み時に `manifest` が見つからない | ZIP を展開したか、`manifest.json` が直下にあるフォルダーを選んだか確認します。「Source code (zip)」ではなくビルド済み ZIP を使ってください。 |
| 翻訳ボタンが出ない | Chrome で開いた `discord.com` か確認し、拡張とポップアップのスイッチをオンにして、Discord のタブを再読み込みします。 |
| 翻訳でエラーが出る | 表示された理由を確認します。選択した翻訳サービスとキーが一致しているか、サービス側の利用枠が残っているかを確認してください。設定画面の「テスト」でも接続確認できます。 |
| 更新後に拡張が二つ並ぶ | 別のフォルダーから新規登録した可能性があります。片方をオフにし、使う方で設定と動作を確認してから、不要な方を整理してください。 |

Discord の画面変更や翻訳 API の仕様変更で動作しなくなる場合もあります。不具合を報告する際は、API キーやサーバー内の非公開メッセージを貼らないでください。
