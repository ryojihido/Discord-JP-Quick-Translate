Discord JP Quick Translate v1.0.2

パソコンの Chrome で開いた Discord の文章を、クリックしたときだけ翻訳する非公式拡張です。
Discord のデスクトップアプリ・スマートフォン用ではありません。

【使う前に】
・Discord による承認・提携・後援は受けていません。
・Chrome ウェブストアには掲載していません。
・Chrome の「デベロッパーモード」と手動での読み込みが必要です。自動更新もありません。
・ページに表示されたメッセージを読み取り、翻訳ボタンを追加します。
・翻訳を押した文章の対象部分を、選択した DeepL または Google の翻訳 API へ送ります。
・自分の API キーが必要です。サービスの契約・利用量に応じて費用がかかる場合があります。
・機密情報など、外部の翻訳サービスへ送れない文章には使わないでください。

【導入】
1. ZIP を「すべて展開」します。展開したフォルダーは、ドキュメント内など使い続ける場所に置きます。
2. Chrome 114 以降で、アドレスバーに chrome://extensions/ と入力します。
3. 右上の「デベロッパーモード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」を押します。
5. このファイルと manifest.json が入っているフォルダーを選びます。
6. Chrome 右上の拡張機能ボタンからこの拡張を開き、「設定を開く」を押します。
7. 自分の DeepL API Free または Google Cloud Translation API のキーを入力します。
8. 「使用する翻訳サービス」を選び、「設定を保存」を押します。
9. Chrome で Discord を開くか、開いているタブを再読み込みします。
10. メッセージにマウスを重ねて「翻訳」を押します。

読み込み後も展開したフォルダーを使うので、移動・削除しないでください。
Node.js のインストールやコマンド入力は不要です。
DeepL API Pro の接続先には対応していません。選択したサービスだけを使います。
「テスト」は入力中のキーで Hello を翻訳する実通信で、API 使用量に含まれます。

【更新】
新しいビルド済み ZIP を別の場所に展開し、中身を現在読み込んでいるフォルダーへコピーして上書きします。
manifest.json の場所を変えず、chrome://extensions/ の既存の拡張の再読み込みボタンを押してください。
続いて Discord のタブも再読み込みします。
更新のために拡張を削除したり、別フォルダーから新規登録したりすると、設定が引き継がれないことがあります。
